2. Fetch and Merge Operation(created file in remote): remote to local 
-------------------------------------------------
step 1:fetch latest changes

command: git fetch origin

step 2:check the status

command: git status

step 3:view the difference

command: 

git diff HEAD origin/main


step 4:merge the changes

git merge origin/main

3. Pull Operation:
------------------

 pull = fetch + merge

4. reset and revert: undo the commits
---------------------

before push: 

git log --oneline

git push -u origin main

echo "# file4" >> file4.txt

but I want to delete file4 on both local n remote

git reset --hard HEAD~1

revert: unlike reset it won't delete commit changes permanently.instead of deleting changes it will create new commit it reverts to the selected commit.
